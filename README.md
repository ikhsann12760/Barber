# Daddy's Cut Barber & Coffee

Website management untuk Daddy's Cut Barber & Coffee dengan integrasi Midtrans Payment dan Admin Dashboard.

## Fitur
- Booking Online
- Pembayaran via Midtrans (QRIS, Bank Transfer, dll)
- Admin Dashboard terproteksi Auth
- Bot WhatsApp Integration

## Tech Stack
- Next.js 15
- Prisma ORM
- SQLite (Local)
- NextAuth.js
- Tailwind CSS
- Midtrans SDK
